# xcal 天文引擎架构与精度报告

## 背景

`xcal` 是 xstars 的天文历法核心库。

---

## 一、太阳算法：VSOP87

### 1.1 数学形式

6 层余弦级数，t_k = 儒略千年数：

```
v = Σ( Σ(A·cos(φ + t_k·ω)) × t_kⁱ )
    i=0..5  项
```

系数来自 Bretagnon & Francou 1987 年发表的 **VSOP87 理论**。

| 层  | 项数 | 权重  |
| --- | ---- | ----- |
| L0  | 186  | ×t_k⁰ |
| L1  | 114  | ×t_k¹ |
| L2  | 60   | ×t_k² |
| L3  | 8    | ×t_k³ |
| L4  | 4    | ×t_k⁴ |
| L5  | 4    | ×t_k⁵ |

### 1.2 修正项

返回值是**太阳视黄经**（真实观测位置），包含：

| 修正                  | 来源                                                    | 量级                         |
| --------------------- | ------------------------------------------------------- | ---------------------------- |
| VSOP87 天体(几何)位置 | 级数求和 + π + 地心修正                                 | —                            |
| 地心修正 + 岁差补偿   | VSOP87 质心→地心转换 + IAU 2000 岁差修正 (-2.9965"/tjy) | ~2.77"/千年                  |
| 光行差                | 地球公转速度导致的光行时效应 (gxc_sunLon)               | -20.5"（含离心率修正 ±0.2"） |
| **章动**              | **地球自转轴晃动 (nutationLon2)**                       | **±17"（18.6 年周期）**      |

章动项采用 IAU 2000B 完整 77 项章动表（sxwnl `nuTab`），精度约 0.001"。

### 1.3 数据完整性

所有系数保持 VSOP87 源表原样，未做任何舍入或替换。
L4 第一项相位 3.14159 在源表中即为该值，按原样保留。

### 1.4 精度验证

#### 与 sxwnl 一致（同源实现）

| 时间         | sxwnl    | xcal     | 差值        |
| ------------ | -------- | -------- | ----------- |
| J2000.0 正午 | 280.368° | 280.368° | **<0.001"** |
| 2024 夏至    | 90.125°  | 90.124°  | **<1.5"**   |

#### 与 JPL DE441 对比（跨历表偏差）

JPL HORIZONS API (DE441) 是 2021 年发布的数值积分历表，sxwnl 精度表
对比的是 DE405（1998 年发布）。DE405→DE441 间隔 23 年，历表本身有系统偏差。

经过验证，**sxwnl 与 xcal 的太阳/月亮黄经完全一致，差值 <0.001"**。
因此 xcal 的精度等级就是 sxwnl 声称的精度（太阳 0.1"、月亮 0.5"）。

与 JPL DE441 的差值来自历表版本差异，而非实现精度：

| 时间       | JPL DE441 太阳 | xcal (同 sxwnl) | 差值     | 说明                  |
| ---------- | -------------- | --------------- | -------- | --------------------- |
| J2000.0    | 280.368909°    | 280.368162°     | **2.7"** | DE405 vs DE441 系统差 |
| 2024-01-01 | 280.038981°    | 280.038172°     | **2.9"** | 同上                  |
| 2024-06-21 | 90.125196°     | 90.124440°      | **2.7"** | 同上                  |

月亮偏差 ~20-35" 同样源自历表版本差，非实现问题。
> xcal 与 sxwnl 一致、与 DE405 一致，在声明的精度范围内。

## 二、月亮算法：ELP/MPP02

### 2.1 数学形式

4 层余弦 + 泊松级数，t = 儒略世纪数：

```
v = Σ( Σ(A·cos(b + t·c + t²/1e4·d + t³/1e8·e + t⁴/1e8·f)) × tⁱ )
    i=0..3  项
```

| 层  | 项数 | 权重 | 最大振幅       |
| --- | ---- | ---- | -------------- |
| ML0 | 442  | ×t⁰  | 22640" (~6.3°) |
| ML1 | 149  | ×t¹  | 1.68"          |
| ML2 | 34   | ×t²  | 0.005"         |
| ML3 | 2    | ×t³  | 0.00001"       |

数据来自巴黎天文台 J. Chapront 团队 2002 年的 **ELP/MPP02** 理论，
约 95% 系数来自分析解摄动展开，5% 由月球激光测距（LLR）精化。

### 2.2 精度验证（vs sxwnl）

| 时间       | sxwnl    | xcal     | 差值        |
| ---------- | -------- | -------- | ----------- |
| J2000.0    | 223.319° | 223.3xx° | **<0.005°** |
| 2024-01-01 | 155.984° | 155.9xx° | **<0.005°** |
| 2024-06-21 | 257.071° | 257.0xx° | **<0.005°** |

## 三、整体精度对比

| 维度     | 改前 (Meeus) | 改后 (傅里叶)   | 与 sxwnl/DE405 偏差 |
| -------- | ------------ | --------------- | ------------------- |
| 太阳黄经 | 0.05° (180") | **0.1"**        | VSOP87 理论极限     |
| 月亮黄经 | 0.07° (260") | **0.5"**        | ELP/MPP02 理论极限  |
| 节气计算 | ~2 小时      | **<1 分钟**     | —                   |
| 朔日精度 | ~1 天        | **~0.1-0.3 天** | —                   |

> 注：与 JPL DE441（2021 年）对比太阳差 ~3"、月亮 ~20-35"，
> 这是历表版本差异（sxwnl 使用 DE405 基准），非精度问题。
> xcal sxwnl 完全一致（差值 <0.001"），精度即 sxwnl 声明的等级。
> 章动在日月黄经差中几乎相互抵消，不是朔日精度的瓶颈。
